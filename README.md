# HERMANOS UNIDOS - CONTROL TOTAL

## ZIP DEFINITIVO CON CONTROL TOTAL DE CADA VENTANA

Contraseña panel: Todocasero.2020 (en admin.js)

### 10 VENTANAS EDITABLES DESDE PANEL:

1. GENERAL: Nombre iglesia, subtitulo, colores
2. HERO: Título, subtítulo, devocional título y texto
3. PREDICAS: Agregar/editar/borrar prédicas con categoría y pastor
4. VIDEOS: Agregar/borrar videos YouTube (solo ID)
5. TESTIMONIOS: Agregar/borrar testimonios
6. SEDES/HORARIOS: Agregar/borrar sedes de todo el país con WhatsApp y dirección
7. RADIO/MUSICA: Nombre radio, agregar/borrar música YouTube playlist
8. DONACIONES: Cambiar alias (maxinaranja2025), meta, sumar donaciones
9. WHATSAPP: Mensaje diario editable con {nombre} {link}, exportar CSV, copiar números
10. ESTADISTICAS: Visitas, suscriptos, donaciones, oraciones

### COMO SUBIR A GITHUB:

1. github.com/new -> hermanos-unidos -> Create
2. Sube los 5 archivos
3. Settings > Pages > main > Save
4. Web: https://tuusuario.github.io/hermanos-unidos/
5. Panel: https://tuusuario.github.io/hermanos-unidos/admin.html -> Todocasero.2020
